# Модуль регистрации посетителей

Курсовой проект по теме «Разработка модуля регистрации посетителей для веб-приложения».
Приложение запускается локально, интерфейс открывается в браузере, учётные записи хранятся в PostgreSQL.

## Возможности

- Регистрация по электронной почте и паролю с проверкой введённых данных.
- Хранение хешей паролей Argon2 и проверка уникальности почты.
- Подтверждение почты по одноразовой ссылке со сроком действия 24 часа.
- Повторная отправка письма подтверждения.
- Вход, личный кабинет и выход из аккаунта.
- Сессии в подписанной cookie и проверка CSRF-токена при входе и выходе.

Посетитель может использовать Gmail, Яндекс, Mail.ru или другой почтовый адрес.
Сначала нужно зарегистрироваться, подтвердить адрес и войти с паролем, созданным
для этого приложения. Пароль от самого почтового ящика при входе на сайт не нужен.
Почтовый сервис отправителя писем настраивается отдельно от адресов посетителей.

## Технологии

Python 3.12, FastAPI, Uvicorn, Pydantic, SQLAlchemy, asyncpg, PostgreSQL и Alembic.
Для работы с паролями используется pwdlib с Argon2, для сессий — Starlette и itsdangerous.
Настройки загружаются через python-dotenv. Письма отправляются через настраиваемый SMTP средствами smtplib.
Интерфейс написан на HTML и CSS. Версии библиотек указаны в `requirements.txt`.

## Установка

Команды ниже предназначены для macOS и Linux. Перед установкой подготовьте Python 3.12,
Git и запущенный PostgreSQL. На macOS можно использовать Postgres.app.

```bash
git clone https://github.com/Kkalochek/VisitorRegistration.git
cd VisitorRegistration
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Настройка базы данных

Для нового экземпляра приложения подключитесь к PostgreSQL под учётной записью
с правами создания пользователей и баз данных. В Postgres.app обычно подходит команда

```bash
psql -d postgres
```

В консоли `psql` создайте пользователя и базу. После `\password` задайте пароль пользователя базы

```sql
CREATE ROLE visitor_app LOGIN;
\password visitor_app
CREATE DATABASE visitor_registration OWNER visitor_app;
\q
```

Параметры подключения к базе заданы в `database.py`.

## Настройка почты и переменных окружения

Создайте локальный файл настроек по образцу

```bash
cp -n .env.example .env
```

Заполните `.env`. Код читает параметры через `config.py`; адрес отправителя,
пароль, SMTP-сервер и ссылка на сайт не записаны в Python-файлах.

| Переменная | Значение |
|---|---|
| `DB_PASSWORD` | Пароль пользователя PostgreSQL `visitor_app` |
| `APP_HOST` | Адрес, на котором приложение принимает подключения |
| `APP_PORT` | Порт приложения |
| `APP_BASE_URL` | Полный адрес сайта для ссылок в письмах |
| `SMTP_HOST` | Сервер отправки почты |
| `SMTP_PORT` | Порт SMTP-сервера |
| `SMTP_SECURITY` | `ssl` для TLS сразу при подключении или `starttls` для STARTTLS |
| `SMTP_USERNAME` | Логин ящика отправителя, обычно полный почтовый адрес |
| `SMTP_PASSWORD` | Пароль приложения почтового сервиса |
| `SMTP_FROM` | Адрес отправителя; пустое значение использует `SMTP_USERNAME` |
| `SESSION_SECRET` | Необязательный постоянный случайный ключ подписи сессий |

Адрес SMTP-сервера, порт и режим шифрования возьмите из справки выбранного
почтового сервиса и укажите в своём `.env`. Поддерживаются SSL/TLS и STARTTLS.
TLS-сертификат сервера проверяется. Подготовьте настройки ящика и пароль приложения

- [Gmail](https://support.google.com/accounts/answer/185833)
- [Яндекс](https://www.yandex.ru/support/yandex-360/customers/mail/ru/mail-clients/others)
- [Mail.ru](https://help.mail.ru/mail/login/mailer/)

Если проект уже был настроен с Gmail, перенесите значение `GMAIL_ADDRESS`
в `SMTP_USERNAME`, а `GMAIL_APP_PASSWORD` в `SMTP_PASSWORD`. Старые имена больше
не используются. `DB_PASSWORD` и существующий `SESSION_SECRET` сохраните.
Добавьте остальные параметры из `.env.example`, не перезаписывая свой `.env`
пустым образцом. После изменения настроек перезапустите сервер.

Для доставки писем нужен интернет. При использовании локального адреса ссылку
нужно открывать на том компьютере, где запущено приложение. При публикации
укажите внешний адрес в `APP_BASE_URL`; `APP_HOST` задаёт адрес прослушивания,
который может отличаться от адреса сайта.

Файл `.env` содержит личные настройки и должен быть исключён из Git.
В `.env.example` публикуются только имена переменных с пустыми значениями.
Рабочие адреса, порты, логин и пароли заполняются в локальном `.env`.

## Миграции и запуск

В папке проекта с активированным виртуальным окружением выполните

```bash
python -m alembic upgrade head
python VisitorRegistration.py
```

Миграции создают таблицы `users` и `email_verification_tokens`.
Откройте в браузере адрес из `APP_BASE_URL`, добавив к нему путь `/register`.
Зарегистрируйтесь, откройте ссылку из письма и войдите через страницу `/login`.
Остановка сервера выполняется сочетанием `Ctrl+C` в терминале.

При последующих запусках откройте папку проекта, запустите PostgreSQL и выполните

```bash
source .venv/bin/activate
python VisitorRegistration.py
```

По умолчанию ключ подписи сессий генерируется при старте процесса, поэтому после
перезапуска сервера потребуется повторный вход. При необходимости постоянный ключ
задаётся переменной `SESSION_SECRET` в локальном `.env`.
